FEATURES

What is implemented
in the app today.

This page lists only behaviour that exists in the source. If a capability is not listed here, treat it as not implemented.

IMPLEMENTED ONLY

Capacity with boundaries.

Each card names the code path behind it. Release status is separate: the app is not published, and runtime behaviour has not been verified on a distributed APK.

PROVIDER

AI build planning

A real Google Gemini provider adapter with user-supplied API keys, model selection, connection testing, cancellation, and explicit provider error reporting.

Implemented
REFERENCE

Image references

One validated JPEG, PNG, or WebP image per request, prepared and bounded locally before it is sent as vision input.

Implemented
REFERENCE

Narrow public video references

Direct public HTTPS MP4/WebM files on raw.githubusercontent.com that support byte ranges, sampled into at most five frames for a verified Multi-image Vision model. No web pages, playlists, redirects, or private sources.

Implemented
PLAN

Bounded BuildPlan v2 validation

Structural parsing plus dimension, component, material, floor, and operation limits. Provider output that fails validation is reported as invalid, never rendered as a build.

Implemented
REVIEW

Review, refine, and version

A human-readable review with expandable technical detail, refinement through a new provider request, and immutable saved versions with diffs.

Implemented
HISTORY

Local build history

Accepted builds are stored in app-private storage with their source type, status, and version chain. No account needed, no cloud sync, no analytics.

Implemented
INTERFACE

Light and dark themes with reduced motion

Appearance follows the system or your choice, and the app honours the platform animation-scale setting so motion is never required to understand a status.

Implemented
MINECRAFT

Bridge pairing and runtime detection

Private-LAN HTTPS pairing with a pinned TLS identity, authenticated capability exchange, automatic runtime detection, deterministic adapter selection, and compatibility resolution.

Implemented
MINECRAFT

Preflight, confirmation, and progress

A server-side preflight of the accepted plan, a separate explicit confirmation, bridge-reported progress, and cancellation with a bridge-confirmed terminal state.

Implemented
MINECRAFT

Certified Java 1.20.1 production target

Minecraft Java 1.20.1 with Fabric Loader 0.16.10 and Fabric API 0.92.2+1.20.1 is the shipped certified production record. Building there is authorized only when every gate passes.

Implemented · certified record
MINECRAFT

Honest experimental runtimes

Bedrock and legacy Java runtimes are recognized, reported as experimental, and never authorized to build. CraftMind does not approximate a nearby version or cross editions.

Implemented
ACCOUNT AUTHENTICATION · OTHER SERVICES NOT IMPLEMENTED

Account security, without cloud sync

The app and repository include registration, email verification, sign-in, password recovery/change, and session controls against a configured account service. No production account endpoint or mail provider is operated by this repository, and builds/settings are not synced. The marketplace, creator dashboards, payments, and subscriptions are not implemented.

Auth supported · no hosted service

Limits we state out loud

  • AI output is not a guarantee. Generated geometry can be inaccurate or incomplete, and CraftMind does not promise an exact visual reconstruction of your reference.
  • Minecraft block placement cannot be rolled back by the app. Inspect the plan and the server preflight before you confirm.
  • Only one visual reference is accepted per request, and video support is deliberately narrow.
  • The bridge is a server-side Fabric mod for a specific Java target; it is not a remote-control tool and exposes no shell or arbitrary command surface.
  • Nothing here has been verified on a signed, installed release build, and no runtime certification exists for Bedrock or legacy Java.
