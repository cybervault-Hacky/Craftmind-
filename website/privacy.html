PRIVACY

Privacy summary

This page summarises the data flow that is actually implemented in the app. It is a product summary, not legal advice, and it does not replace Google's provider terms.

DATA FLOWS

Five flows, in plain language.

The app has no account-service URL by default. The repository includes an optional authentication service for configured builds, but no production endpoint or mail provider is operated here. CraftMind has no AI proxy backend and no telemetry.

⌑

Credential storage

The provider key is encrypted with AES-GCM using a key held by the Android Keystore and saved in app-private no-backup storage. It is never included in a Minecraft bridge request and never shown back in full.

◎

Optional account authentication

Only a build configured for an HTTPS CraftMind account service sends account details. That service stores email and display name, a salted scrypt password hash, guest identity, session-token digests, and one-time-token digests. It does not store plaintext passwords or raw token values. Account deletion is unavailable.

↗

Direct provider requests

Prompts and the visual input you choose are sent from the device directly to Google over HTTPS. Video bytes are fetched in bounded ranges and only sampled frames are sent. Provider-side retention follows Google's terms.

▤

Local history

Build versions and reference metadata — including a direct video URL — are saved locally in app-private storage. Raw image, video, and frame bytes are not saved in build history.

◇

Optional Minecraft link

Bridge pairing uses pinned private-LAN HTTPS and a paired identity. Only an accepted, preflighted plan can proceed, and only after your separate confirmation. The bridge never receives the provider API key.

What you control

  • Your provider credential lives only in app-private storage; you can remove it from Settings, and clearing the app's data or uninstalling removes it.
  • Your bridge profile is stored the same way and can be forgotten from the pairing screen.
  • Build history is local and is not synced to an account. Clearing app data removes it.
  • Account deletion is unavailable. The app may explain that status, but the account service has no deletion endpoint and no account or device data is removed by such a request. A production operator must publish data-handling and retention details before accepting users.
  • No analytics, crash-reporting, advertising, or tracking SDK is included in the app or on this website.

What leaves your device

  • If an account-service URL is configured, the submitted email, display name, password during sign-up/sign-in or password change, one-time code, and opaque session credentials travel to that service over HTTPS. Passwords are hashed before storage; session credentials are kept in the Android Keystore-backed store.
  • Your prompt and any chosen visual reference, sent to Google Gemini over HTTPS with your key.
  • A bounded execution request sent to your paired Minecraft bridge over pinned private-LAN HTTPS — never your API key.
