Why is it not available? ↗

DISTRIBUTION

Direct from this website.

The binary lives with the source: the APK is an asset on a GitHub Release of this repository, and this website — hosted on Netlify, which serves no binaries — links to that asset and to the checksum GitHub publishes with it. Keeping the file out of the site's own source tree means no generated artifact is ever committed, and one release page stays the place a build is described, versioned, and superseded.

  • Binary — the APK attached to a published GitHub Release of this repository
  • Link — this page, with the asset resolved live so a removed release cannot leave a dead promise
  • Verification — compare the published SHA-256 before installing
  • Today — no release exists, so no APK, no checksum, and no installer to sideload

INSTALLATION

When the signed APK is published.

There is no installer today. These are the steps the release will document, in order.

  1. 01

    Download the APK and its SHA-256 checksum from the official CraftMind website.

  2. 02

    Verify the checksum before installing. Never install a build from an unverified mirror.

  3. 03

    Open CraftMind, save your own Gemini API key in Settings, test the connection, and select a compatible model.

  4. 04

    Pair a supported private-LAN Fabric bridge only if you want to execute an accepted plan in game.

Security and integrity

Only a signed build will be published, and only alongside its checksum. The download button on this page stays disabled until that artifact exists — CraftMind never ships a placeholder APK, and this website never links to an unverified binary. A debug build from a workflow run is a test artifact for a device you own: it is signed with a throwaway debug key, arrives through a GitHub Actions artifact rather than a release, and is never presented here as the app's release.

Android will refuse to install a build from outside the Play store until you allow it for the app you used to fetch the file, and it will warn you about an unrecognised publisher. Read those prompts and act on them: install the file this page linked, whose checksum you compared, and nothing else.

App-side, your provider credential is encrypted with AES-GCM using a key held by the Android Keystore and stored in app-private, no-backup storage. The credential is never sent to the Minecraft bridge and is never displayed back to you in full.
