A HUMAN-IN-THE-LOOP WORKFLOW

From a thought
to a plan you can inspect.

CraftMind is an AI-first planner, not a manual block editor. The app code implements these steps; a signed release build and end-to-end device verification are still pending.

01

Describe

Write what you want to build. CraftMind sends the request directly to the selected Google Gemini model using the key you provide.

02

Show (optional)

Add one locally checked JPEG, PNG, or WebP image—or a narrowly supported public MP4/WebM file URL. One visual reference at a time.

03

Review the AI plan

Provider output must pass CraftMind's bounded BuildPlan v2 parsing and validation. You inspect and accept a plan before it enters the saved build history.

04

Build only if you choose

An optional compatible Fabric bridge checks the accepted plan on the server. A separate final confirmation is required; reported progress comes from the bridge.

CAPABILITIES & BOUNDARIES

Specific by design.
Honest about limits.

Only the workflows and compatibility actually present in this repository are described here. Runtime behavior has not been certified for a distributed APK.

A

Google Gemini, directly

Gemini is the implemented provider adapter. A user-supplied API key and internet access are required; provider account terms, quotas, and any charges are between you and Google. No CraftMind AI backend is included.

B

Images and a narrow video path

Image analysis is limited to validated, locally prepared images and models marked Vision. Video is limited to direct public HTTPS MP4/WebM files on raw.githubusercontent.com that support byte ranges; up to five sampled frames need a verified Multi-image Vision model. No web pages, social-video sites, playlists, redirects, or private sources.

C

A server bridge, not a remote-control tool

The configured bridge target is a server-only Fabric mod for Minecraft Java 1.20.1, Java 17, Fabric Loader 0.16.10, and Fabric API 0.92.2+1.20.1. Pairing is private-LAN HTTPS with pinned identity. No shell, arbitrary commands, or public relay.

D

AI is not a guarantee

Generated geometry may be inaccurate or incomplete. Inspect every plan and server preflight result. CraftMind does not promise exact visual reconstruction, Minecraft block placement cannot be rolled back by the app, and this bridge is not verified with third-party protection mods.

PRIVACY BY ARCHITECTURE

Your key stays yours.

This is a product data-flow summary, not a replacement for Google's provider terms.

⌑

Credential storage

The provider key is encrypted with AES-GCM using a key held by Android Keystore and saved in app-private no-backup storage. It is never included in the Minecraft bridge request.

↗

Direct provider requests

Prompts and chosen visual input are sent from the device directly to Google over HTTPS. Video bytes are fetched in bounded ranges; sampled frames go to Gemini. Provider-side retention follows Google's terms.

▤

Local history

Build versions and reference metadata—including a direct video URL—are saved locally in app-private storage. Raw image, video, and frame bytes are not saved in build history. There is no CraftMind account or cloud sync.

◇

Optional Minecraft link

Pairing uses pinned private-LAN HTTPS. Only an accepted, preflighted plan can proceed after a separate user confirmation. The bridge does not receive the provider API key.

INSTALLATION

When the signed APK is published.

There is no installer to sideload today. When a release exists, use only the signed APK attached to the official repository release and compare its published SHA-256 checksum.

  1. 01

    Download the APK and checksum from the official CraftMind release page.

  2. 02

    Verify the checksum. If Android asks, allow installation only for the file source you deliberately chose.

  3. 03

    Open CraftMind, save your own Gemini API key in Settings, test the connection, and select a compatible model.

  4. 04

    Pair a supported private-LAN Fabric bridge only if you want to execute an accepted plan in game.
