CREATORS

The people
behind the builds.

Creator profiles are real and server-owned: each one is readable at a handle, and the profile page reads it directly. A browsable directory — search, categories, follower counts — and listings and ratings belong to the marketplace service, which does not exist yet, so this page shows no invented creators and no fabricated statistics, only the layout that will hold them.

DIRECTORY

Browse creators.

Creator search, categories, and follower counts need a directory service, which is not implemented. Review the layout with sample records by adding ?preview=1 to this address.

PLANNED

Creator profiles

Display name, a handle, a bio, and the categories a creator works in. A single profile is already served by the account service and readable at its handle; browsing many creators at once needs the directory below.

PLANNED

Ratings and reviews

A rating appears only when buyers have left real reviews. An account with no reviews shows “No ratings yet” rather than an empty five-star row.

PLANNED

Following

Following, saving, and wishlists need account-scoped storage. In this phase, saving keeps an item in the current page only and is never sent anywhere.
