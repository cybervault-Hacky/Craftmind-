ACCOUNT RECOVERY

Prove the code,
then change the password.

CraftMind recovers an account with a one-time code, the same mechanism the Android app uses. There is no link to click that carries your credentials for you: the message contains a code, you paste it below with a new password, and the account service replaces the password and revokes every session it holds for that account. This page works while you are signed out — that is the point of it.

How this works, and what it does not do

Every statement below describes the account service that exists in this repository, not a plan.

THE CODE ITSELF

Single use, and it expires

A recovery code works once. It stops working at the expiry time the message states, and a used or expired code cannot be revived — the service refuses it and your password stays exactly as it was. Requesting another code replaces the outstanding ones.

NO ACCOUNT ENUMERATION

The answer never confirms an address

The request endpoint answers the same way whether or not an eligible account exists, so this page cannot be used to test an email address. A code is issued only for an active account with a verified email address, and that stays the server's decision.

WHAT CHANGES ON SUCCESS

New password, all sessions gone

The service replaces the password hash and revokes every session for the account — including any that were stolen. You sign in again afterwards. Nothing is emailed back to you, and the code is never returned in a response or a log line.

HONEST LIMITS

What recovery cannot do here

There is no phone verification, no multi-factor reset, no backup-code vault, and no support agent who can reset a password for you. Mail delivery is best-effort with no durable queue, so a missing message is a real possibility rather than a promise you can hold this site to.

This page needs JavaScript, because the account service answers JSON and there is no form to post to a server here. It never puts the code or the new password in the address bar, in browser storage, or in a log, and it never reads a recovery code from a URL parameter.
