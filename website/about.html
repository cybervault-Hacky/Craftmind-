About CraftMind

CraftMind is an independent, review-first AI build planner for Minecraft: you describe what you want, AI designs a plan, and nothing is built until you have inspected it and confirmed it yourself.

What CraftMind is

CraftMind is an Android application that turns a natural-language idea — optionally with one visual reference — into a structured, validated Minecraft build plan that you review before anything happens in your world. It is not a manual block editor, and it is not a hosted service: the AI provider is called directly from your device with your own key.

Mission

Make AI-assisted building in Minecraft inspectable. The interesting part of an AI build is not the animation — it is whether the plan is valid, whether your server can run it, and whether you agreed to it.

Philosophy

  • Review before execution. A plan becomes a build only after validation, a server preflight, and your separate confirmation.
  • Real status only. No invented percentages, no simulated progress, no decorative animation standing in for work.
  • Narrow and honest compatibility. One certified production target, clearly labelled experimental runtimes, and no guessing between versions or editions.

Technology, at a high level

The Android app is written in Kotlin with Jetpack Compose. A small Java module defines the bridge protocol shared by the app and the server mod. The bridge itself is a Fabric server mod for Minecraft Java 1.20.1. The website you are reading is static HTML and CSS with no tracking scripts.
