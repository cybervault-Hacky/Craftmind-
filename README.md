# CraftMind

**AI Minecraft Builder** · *Describe it. Show it. Build it.*

CraftMind is an Android app for turning a written request into an AI-designed, validated Minecraft build plan. Build plans are generated by a configured AI provider; there is no manual block-layout editor or built-in template generation.

## Phase 2 pipeline

**Validated request → selected provider and model → direct provider HTTPS request → strict BuildPlan v1 parsing and validation → local record and review**

The AI provider designs every plan. CraftMind displays a plan only after the response parses as the supported schema and passes centralized limits and block/state validation. A validated plan is offered for review and saved to local history when storage succeeds; persistence failures are disclosed. CraftMind does **not** execute it in Minecraft.

## Supported today

- **Provider adapter:** one built-in Google Gemini REST adapter. It lists the provider's current models using the provider API, then supports text generation with JSON MIME output for a model the user selected. Model availability can change; the app rechecks the list when testing and generating. No other provider is presented as available.
- **Provider setup:** enter, replace, remove, and test a Google-owned API key in Settings; select a model only after a live authenticated model-list request succeeds. A saved key alone is not shown as a working connection.
- **Credential privacy:** AES-GCM-encrypted provider keys in app-private no-backup storage, with the AES key held by Android Keystore. Keys are not put in preferences, logs, URLs, a CraftMind backend, build records, or the Minecraft bridge. Stored values are never prefilled into the UI.
- **BuildPlan v1:** strict JSON parsing rejects unknown fields, malformed or unsupported schemas, invalid coordinates/dimensions, duplicate positions, unsupported operations, unlisted block IDs/states, and oversized content. Central limits include 96 × 64 × 96 blocks, 64 components, 4,096 placements, and a 4 MiB provider response.
- **Local history and review:** only a parsed and validated AI plan is added to the local Builds list. The review screen shows plan metadata, components, block counts, a bounded placement preview, and the original request references.
- **Request references:** JPEG, PNG, and WebP image references and HTTP(S) URL references can be preserved with the local request record. They are **not uploaded, fetched, or analyzed** by the current adapter. The provider receives the written prompt and a disclosure that references exist but are unavailable to analysis; the actual image URI and URL are not sent.
- **Network behavior:** the adapter contacts Google's built-in HTTPS API endpoint directly. It uses bounded response bodies, connection/read/write/call timeouts, cancellation propagation, safe status mapping, disabled redirects, and no automatic retries. The user may manually retry retryable failures.

## Not implemented

- Gemini vision/image analysis, URL fetching or analysis, or support for restricted/social content.
- Other provider adapters or user-configurable endpoints.
- Minecraft pairing, world connection, block placement, or execution progress.
- Manual build editing, templates, fake generation/progress, monetization, ads, payments, credits, or premium tiers.

## Provider verification

A provider is reported as connected only after the app makes a real authenticated HTTPS request to list compatible models. Generation also rechecks the selected model and accepts only a real provider response that passes local validation. This repository does not contain provider keys. A live account/key was not available during implementation, so a real Google account connection has not been exercised here; the adapter's HTTP contract is covered by local TLS-backed tests.

## Project and verification

- Application ID: `com.craftmind.app`
- Android: Kotlin, Jetpack Compose, Material 3
- Architecture: `presentation/`, `domain/`, `data/`, and `designsystem/` boundaries
- Minimum Android version: API 26; compile/target SDK: 35
- Java toolchain: 17

With JDK 17 and Android SDK 35 installed, run:

```bash
./gradlew test
./gradlew lint
./gradlew assembleDebug
./gradlew connectedDebugAndroidTest
```

Builds and tests must be run in that environment; the presence of these commands does not imply that they have passed in this checkout.
